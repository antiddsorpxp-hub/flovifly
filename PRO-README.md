# Viole Messenger Pro 3.0

Это усиленная рабочая сборка Viole под Render. Она не является копией Telegram и не может честно обещать «лучше Telegram» за один архив, но включает профессиональную базу: профили, аватары, bio, личные чаты, группы, каналы, поиск, добавление участников, реакции, ответы, редактирование, удаление, файлы, голосовые, PWA, фиолетовый UI и WebRTC-звонки.

## Как обновить Render

1. Распакуй архив.
2. Открой GitHub репозиторий.
3. Загрузи содержимое папки `viole` в корень репозитория, не сам ZIP и не внешнюю папку.
4. Подтверди замену файлов и нажми `Commit changes`.
5. Дождись окончания Deploy на Render.

Не удаляй Disk `viole-data` и путь `/app/data`. Перед изменениями сделай копию `data/db.json` через `sh backup-data.sh`, если работаешь локально. На Render секреты задаются в Environment, `.env` в GitHub загружать нельзя.

## Что проверить после deploy

Открой сайт в приватном окне и создай тестовый аккаунт. Проверь отдельно: регистрацию, поиск пользователя, личный чат, канал, добавление участника, отправку картинки, голосовое, профиль и звонок. Если звонок не соединяется, добавь TURN-переменные в Render, одного STUN недостаточно.

## Реальные ограничения

Секретные чаты, боты, Stories, стриминг, платежи, большие файлы, push-уведомления и многосерверная нагрузка требуют отдельных сервисов и этапов. Premium-функции Viole здесь доступны бесплатно, но это не даёт доступ к закрытым функциям Telegram.
