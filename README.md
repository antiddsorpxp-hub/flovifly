# Viole 2.0

Фиолетовый realtime-мессенджер: личные и групповые чаты, каналы, ответы, реакции, редактирование и удаление сообщений, закрепы, поиск, файлы, индикатор набора, присутствие и WebRTC-аудио/видео.

## Запуск
```bash
cp .env.example .env
npm install
npm run check
npm run dev
```
Откройте http://localhost:3000 в двух профилях браузера.

## Продакшен
Задайте длинный `JWT_SECRET`, HTTPS и TURN. JSON-хранилище годится для одного процесса/MVP. Перед масштабированием замените адаптер на PostgreSQL и объектное хранилище для файлов.

## Безопасность
HTTP-only cookie, scrypt, timing-safe проверка, лимиты payload, rate-limit авторизации, проверка доступа ко всем чатам и серверная валидация. Не храните секреты в репозитории.

## Viole Final
Добавлены 4 оформленные темы, панель настроек, компактный режим, крупный текст, управление анимациями и уведомлениями, мобильная нижняя навигация, состояния переподключения, проверка офлайна/занятости при звонках и дополнительная защита от дубликатов личных чатов.

Ни один реальный продукт нельзя честно назвать абсолютно свободным от багов без браузерных, нагрузочных и security-тестов. Эта сборка подготовлена как сильный release candidate, а не как фальшивое обещание.

## Профили
Публичная карточка пользователя, редактирование имени и описания, четыре стиля профиля: Violet, Aurora, Mono и Sunset.
