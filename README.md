# Viole 2.0

Готовый mobile-first мессенджер: регистрация только по username, realtime-чаты, присутствие, индикатор набора текста, адаптивный интерфейс и 1:1 WebRTC аудио/видеозвонки.

## Запуск

```bash
cp .env.example .env
npm install
npm run dev
```

Откройте `http://localhost:3000` в двух профилях браузера, создайте двух пользователей и начните чат.

## Продакшен

Обязательно задайте длинный `JWT_SECRET`, HTTPS и TURN-сервер. Для Render уже есть `render.yaml` с постоянным диском `/app/data`. JSON-хранилище подходит для одного MVP-инстанса; перед горизонтальным масштабированием замените адаптер на PostgreSQL.

## Новое в v4
- Аккаунт-владелец: username `flovifly`, пароль `steve123@`, создаётся автоматически при первом запуске сервера (см. `seedOwner()` в `server.js`). У него переливающийся бейдж **OWNER** рядом с именем везде в интерфейсе.
- Premium-бейдж (★) — переключается в настройках, сейчас бесплатно на время беты. Владельцу выдан по умолчанию.
- Анимированный (переливающийся) аватар-профиль — доступен Premium-пользователям и владельцу, включается тумблером в настройках.
- Настоящие счётчики непрочитанных сообщений в списке чатов (как в Telegram): обновляются в реальном времени и сбрасываются при открытии диалога.

**Важно:** сразу после первого деплоя смените пароль владельца (через смену пароля, если добавите такой эндпоинт) или ограничьте доступ к серверу — пароль `steve123@` захардкожен в исходном коде и виден всем, у кого есть доступ к репозиторию.

## Новое в v5
- Загрузка своей аватарки и баннера профиля — JPG, PNG, WEBP или **анимированный GIF**, до 8 МБ. Реализовано без сторонних зависимостей (multer и т.п.): файл отправляется как raw-body с `Content-Type` картинки и сохраняется в `data/uploads` (попадает на тот же постоянный диск Render, что и `db.json`).
- Кастомный цвет ника — доступен всем, включается тумблером в настройках.
- Градиент ника (2 цвета) и анимация ника (мерцание/радуга/пульс/свечение) — Premium-фичи, как и переливающийся аватар; при отключении Premium сбрасываются автоматически на сервере.
- Эндпоинты: `POST/DELETE /api/me/avatar`, `POST/DELETE /api/me/banner`.

**Следующие этапы (не входят в v5):** каналы и группы (нужна новая модель чатов), групповые звонки (нужен SFU или mesh на несколько участников).
