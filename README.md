# Flovifly 2.0

Готовый mobile-first мессенджер: регистрация только по username, realtime-чаты, присутствие, индикатор набора текста, адаптивный интерфейс и 1:1 WebRTC аудио/видеозвонки.

## Запуск

```bash
cp .env.example .env
npm install
npm run dev
```

Откройте `http://localhost:3000` в двух профилях браузера, создайте двух пользователей и начните чат.

## Продакшен

Обязательно задайте длинный `JWT_SECRET`, HTTPS и TURN-сервер. Для Render уже есть `render.yaml` с постоянным диском `/app/data`. JSON-хранилище подходит для одного MVP-инстанса; перед горизонтальным масштабированием замените адаптер на PostgreSQL.
