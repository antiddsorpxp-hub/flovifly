# Viole Messenger 2.0

Полноценный mobile-first мессенджер и PWA с собственной иконкой Viole. Все функции доступны бесплатно, отдельной платной подписки нет.

## Что уже работает

- регистрация только по username и паролю, Premium включён всем;
- личные чаты, группы, каналы и «Избранное»;
- realtime-сообщения, статусы онлайн, набор текста, счётчик непрочитанных;
- ответы, редактирование, удаление, реакции, закрепление чатов, поиск;
- картинки, PDF, файлы до 4 МБ и голосовые сообщения;
- профиль, имя, bio и аватар;
- аудио/видеозвонки WebRTC;
- адаптивный интерфейс, PWA, установка на телефон/компьютер;
- Dockerfile и готовый render.yaml.

## Быстрый запуск

```bash
cp .env.example .env
npm install
npm run dev
```

Откройте `http://localhost:3000`. Для проверки чата используйте два разных браузера или профиль инкогнито.

## Что и где менять

- `public/index.html` — разметка и тексты интерфейса.
- `public/style.css` — цвета, размеры, мобильная версия.
- `public/app.js` — логика интерфейса, чатов, файлов и звонков.
- `server.js` — API, Socket.IO, авторизация, хранение данных.
- `public/icons/viole.svg` — фирменная иконка. После замены сохраните тот же путь.
- `public/manifest.webmanifest` — название и настройки установки приложения.
- `.env` — секрет и серверы STUN/TURN. Этот файл нельзя публиковать.
- `data/db.json` — данные пользователей и чатов. Не редактируйте вручную на работающем сервере.

## Обновление на GitHub

Распакуйте архив поверх репозитория, затем:

```bash
git add .
git commit -m "Upgrade to Viole Messenger 2.0"
git push origin main
```

Если Render подключён к GitHub, новый deploy начнётся автоматически. В Render обязательно должен быть persistent disk `/app/data`, иначе данные пропадут после перезапуска.

## Продакшен

1. Создайте длинный случайный `JWT_SECRET`.
2. Настройте TURN в `TURN_URL`, `TURN_USERNAME`, `TURN_CREDENTIAL`, иначе звонки не у всех пройдут через NAT.
3. Используйте HTTPS, браузеры блокируют камеру и микрофон без него.
4. Текущее JSON-хранилище подходит одному серверу. Для серьёзной нагрузки перенесите users/chats/messages в PostgreSQL и файлы в S3-совместимое хранилище.

## Важно

Это самостоятельный продукт Viole, а не копия Telegram. В архиве реализован сильный рабочий MVP, но Telegram строился годами: секретные чаты, боты, Stories, платежи, огромные файлы, трансляции, полноценная модерация и многосерверная инфраструктура потребуют отдельных этапов и внешних сервисов.
