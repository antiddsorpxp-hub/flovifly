# Viole Messenger 2.1

Готовая улучшенная версия Viole под Render. Это самостоятельный мессенджер с фиолетовым фирменным стилем, а не копия Telegram.

## Уже есть

Личные чаты, группы, каналы, поиск пользователей, добавление участников, профили с avatar и bio, «Избранное», закрепление, mute, непрочитанные, realtime typing/presence, ответы, реакции, редактирование, удаление, фото, PDF, файлы, голосовые, PWA, собственная иконка, аудио/видеозвонки WebRTC и Premium-функции без платного ограничения.

## Как заменить сайт на Render

1. Скачайте ZIP и распакуйте его.
2. На GitHub откройте репозиторий `antiddsorpxp-hub/flovifly`.
3. Нажмите **Add file → Upload files**.
4. Перетащите все файлы из распакованной папки, не внешнюю папку.
5. Нажмите **Commit changes**.
6. Render автоматически начнёт новый deploy.

Если GitHub спросит о замене файлов, соглашайтесь. На Render не удаляйте Disk `viole-data` и не меняйте путь `/app/data`, иначе потеряются пользователи и переписки.

## Что нельзя трогать

Не удаляйте `.env` на сервере и не публикуйте его на GitHub. В Render откройте **Environment** и храните там `JWT_SECRET`, `TURN_URL`, `TURN_USERNAME`, `TURN_CREDENTIAL`. Persistent disk должен быть подключён к `/app/data`.

## Резервная копия

Перед обновлением локально можно выполнить:

```bash
sh migrate-and-backup.sh
```

На одном Render-сервере JSON с persistent disk подходит для MVP. Для нескольких инстансов и больших файлов следующим этапом нужны PostgreSQL и S3-совместимое хранилище.

## Локальный запуск

```bash
cp .env.example .env
npm install
npm run dev
```

Проверка: `http://localhost:3000`.

## Файлы

`server.js` отвечает за API, Socket.IO, авторизацию и чаты. `public/index.html` отвечает за структуру. `public/style.css` за фиолетовый адаптивный интерфейс. `public/app.js` за профили, каналы, поиск, файлы, реакции и звонки. `public/icons/viole.svg` и `public/manifest.webmanifest` за иконку и установку приложения. `render.yaml` за Render deploy.

## Ограничения честно

Нельзя одной кнопкой включить весь Telegram Premium. Здесь Premium-функции Viole открыты бесплатно, но Telegram-эксклюзивы вроде Stories, ботов, секретных чатов, больших трансляций и многосерверной инфраструктуры требуют отдельных модулей и сервисов.
